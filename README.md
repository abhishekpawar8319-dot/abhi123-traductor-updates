# Traductor – app updates

New versions of the Traductor app (Spanish ⇄ English/Hindi translator and tower erection checklist).

Each version is a **release** here with the APK attached. The app checks this repository when it opens,
shows "Update available" and installs it with one tap. Your checklist and history stay on the phone.

Release tags end with the app's version code, for example `v1.5.3-9`.

To install by hand: open **Releases**, download `SpanishTranslator.apk` and open it on the phone.
